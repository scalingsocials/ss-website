# Founder photos

Sourced from the founders' own team page on the previous WordPress site
(`/elementor-6312/`, now 301'd to `/team/`), so these are the brand's own
photography — not stock. Name↔file mapping was taken from the document order on
that page, where each image is immediately followed by its subject's name.

Consistent as a set: studio cut-outs on a grey ground, 1215×1519 (4:5).
Astro converts to AVIF/WebP and emits srcset at build time.

Replace with higher-resolution originals when the founders supply them — two of
the four are wearing sunglasses, which is not ideal for an expertise/E-E-A-T
headshot, but a real photo of the actual person beats an initials tile.
